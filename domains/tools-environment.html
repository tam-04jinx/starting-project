High-yield distinctions

  • description is required in custom-agent frontmatter; omit tools only deliberately.
  • read and search inspect a repository; add edit, execute, or agent only when needed.
  • Custom-agent YAML uses mcp-servers; JSON MCP configuration uses mcpServers.
  • Top-level command and args identify a local MCP process; top-level url identifies a remote HTTP or SSE server.
  • Use copilot -p for programmatic prompts and --no-ask-user to avoid CI hangs.
