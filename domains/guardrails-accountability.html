Domain 6: Implement guardrails and accountability

Layer preventive, detective, and corrective controls around agent autonomy.

1. Architecture2. Tools3. Memory4. Evaluation5. Coordination6. Guardrails

Control layers

Preventive

Least-privilege tools, rulesets, branch protection, MCP allowlists, and required reviews.

Detective

Code scanning, secret scanning, dependency review, logs, artifacts, and audit events.

Corrective

Stop a session, revert a PR, rotate secrets, or remove access after an incident.

Choose the enforcing control

  • Use rulesets or branch protection to prevent unsafe merges.
  • Use environment required reviewers to gate deployments.
  • Use a pre-tool hook plus branch protection to block direct shell pushes.
  • Use secret scanning for exposed secrets, CodeQL for vulnerable code, and dependency review for dependency changes.
  • Use session logs and the PR timeline to understand agent actions; inspect artifact.destroy in audit logs for manual artifact deletion.

Instructions guide behavior. Tool lists limit capabilities. Hooks intercept actions. Branch policy enforces the repository outcome.

Recall checks
